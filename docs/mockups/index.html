Cursiva · maquetas del MVP

Hito 5, fase 5a · para aprobación

Maquetas estáticas de las ventanas de Cursiva, dibujadas para parecerse a GTK4 y Libadwaita en GNOME 50. Muestran disposición, textos y comportamiento; la app real usará los widgets y las fuentes del sistema. Todo lo que hay en las ventanas es traducible: cambia el idioma arriba para ver los dos. El selector de tema cambia las ventanas entre claro y oscuro.

El dibujo del ratón es original de este proyecto. Pasa el puntero por encima: cada parte es una zona clicable.

Notas

  • Los cambios se aplican al momento; no hay botón de guardar. Un aviso ofrece «Deshacer». La barra escribe cuando dejas de moverla.
  • La barra solo se detiene en valores que el ratón acepta (su lista de DPI, leída del dispositivo).
  • 5b «Con clics» es con clics y sin cambio automático. Necesita un valor documentado de «SmartShift apagado» confirmado en el ratón. Si no existe, el grupo ofrece solo Libre y Automático.

  • «Restaurar predeterminado» usa los valores a los que vuelve el ratón al apagarse: 1000 DPI, umbral 10, sin invertir, con clics.

5 · Primer arranque y problemas

Cursiva

Buscando tu ratón

Cursiva es compatible con el MX Master 3S por Bluetooth. Aparecerá aquí en cuanto se conecte.

EnciéndeloEl interruptor está debajo
Elige el canal de esta computadoraCon el botón de abajo; su luz indica el canal
Revisa el BluetoothDebe estar encendido y el ratón emparejado

Cursiva no puede hablar con el ratón

El ratón está conectado, pero falta un permiso. El instalador lo añade una sola vez; permite que tu usuario, y solo mientras tienes la sesión abierta, hable con dispositivos Logitech.

sudo install -m 644 70-hid-lab-logitech.rules /etc/udev/rules.d/

Después apaga y enciende el ratón. Cursiva nunca necesita permisos de administrador para funcionar.

El servicio de Cursiva no está en marcha

El servicio aplica tus ajustes, incluso con esta ventana cerrada. Normalmente arranca solo; esta vez no lo hizo.

Solaar también está configurando este ratón. Ciérralo o los ajustes pueden cambiar sin control.

(El aviso aparece encima de cualquier vista, no en lugar de ella.)

Notas

  • La app elige la pantalla según el estado del servicio, así nunca adivina: no encontrado, permiso denegado, servicio ausente o conflicto.
  • El servicio arranca solo cuando se le llama (activación por D-Bus), así que «Iniciar el servicio» solo aparece si eso falló. El diagnóstico no lleva dirección Bluetooth ni número de serie.
  • La pantalla de permiso muestra un comando para copiar en lugar de ejecutar sudo: Cursiva nunca pide root.
